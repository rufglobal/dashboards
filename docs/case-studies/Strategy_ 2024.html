Q3-Q4 Intent: GlobalRomania Health

​

Mapping

  • key objective: get ready for launch (Jan 1st)
  • Establish mapping procedures: manual
  • Map out Denver pilot
  • Map out Chicago pilot
  • Sign up mapping volunteers: country

Communication Team

  • wrap up strategic communication message
  • finalize key branding components
  • finalize website campaign pages including website UX testing
  • create quarterly and monthly communication plans
  • go live posting about the project

Online Community

  • decide which software to use
  • structure and prep the community
  • enlist & train community managers
  • start & test betas

Tech Team

  • work with RebelDot to figure out how to automatically generate & hook the doctor “profile” into the community
    • sources: linkedin, professional webpages (hospital)
  • for a given “community” (i.e. city), create a list of local hospitals, universities and other healthcare institutions
  • given a doctor name & hospital: identify contact information (phone, email)
  • identify for a list of hospitals, the actual personnel link where 
  • figure out a way to hook zapier to nationbuilder and google sheets
  • figure out a way to hook zapier from Zoom to Google Drive to automate meeting minutes
  • be the admin for the online platform software

Fundraising Team

  • decide key campaign message
  • test fundraising and see how it goes
  • estimate conversion rates and average dollar raised

Partners Team

  • decide partnering roles and responsibilities
  • signup Romania partners
  • signup diaspora institutional partners
  • signup diaspora community partners

Events Team

  • run 1-2 online and IRL events
  • establish desired event typology that can be replicated
  • engage partners in running events

Admin Team

  • learn how data is preserved at RUF
  • ensure and oversight for data integrity and consistency
  • work with different teams to ensure they have access to the data they need and that they provide accurate data
  • ensure proper import/export and tagging in NationBuilder
  • ensure data between google sheets and nationbuilder is synchronized 
  • ensure profiles shown on website have a minimum of information
